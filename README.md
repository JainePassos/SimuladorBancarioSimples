# SimuladorBancarioSimples
💰 Caixa Eletrônico em Java

Projeto desenvolvido em Java com o objetivo de praticar conceitos fundamentais de programação através da criação de um sistema simples de caixa eletrônico.

📌 Sobre o projeto

O sistema simula as principais operações de um caixa eletrônico, permitindo que o usuário consulte seu saldo, realize depósitos, faça saques e consulte o histórico de operações.

O projeto foi desenvolvido utilizando conceitos básicos de Java, sem utilização de Programação Orientada a Objetos.

⚙️ Funcionalidades

O sistema possui as seguintes opções:

Consultar saldo — exibe o saldo atual da conta.
Depositar — permite adicionar um valor ao saldo.
Sacar — permite realizar um saque desde que haja saldo suficiente.
Sair — encerra o programa.
Extrato — apresenta o histórico das operações realizadas.

📊 Histórico de operações

O histórico utiliza um vetor para armazenar as operações realizadas.

Os depósitos são armazenados como valores positivos e os saques como valores negativos.

Exemplo:

Depósito: R$ 200.00
Saque: R$ -50.00
Depósito: R$ 100.00

A variável quantidadeOperacoes controla quantas posições do vetor estão sendo utilizadas.
